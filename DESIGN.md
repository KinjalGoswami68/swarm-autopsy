SITE DESIGN DIRECTION: METALLIC VIOLET x DEEP BLACK

Design the website around the visual aesthetic of the attached reference
image. I want a premium, solid, futuristic interface using ONLY two
primary color families:
- Deep black (#090909) for the main background.
- Rich metallic plum/violet (#421638 approximately), with muted lavender
  and subtle pink-violet highlights for accents.
The purple should have a reflective metallic finish, not look like a
flat purple gradient. Silver-white typography should complement the dark
surfaces.

1. Overall UI
- Solid, structured and visually strong layouts.
- Large, bold editorial typography with elegant serif headings.
- Clean spacing, sharp visual hierarchy and carefully designed sections.
- Metallic violet panels, buttons, borders and highlights.
- No generic SaaS templates, excessive glassmorphism or random gradients.

2. ASCII Art Experience
Make ASCII art one of the main visual identities of the website.
- Large, artistic ASCII illustrations floating throughout different
  sections.
- ASCII characters should dynamically dissolve, scatter and reconstruct
  as the user scrolls.
- Create depth through layered ASCII compositions.
- Some illustrations should float independently while the page scrolls.
- Use smooth transitions between ASCII patterns and shapes.
- Integrate subtle terminal-inspired details without making the website
  look like an ordinary terminal.

3. Cursor and Motion
Keep the mouse cursor completely SIMPLE. No custom cursor, no oversized
pointer. Instead, make the website itself react to mouse movement.
- When the cursor moves from side to side, nearby ASCII characters
  should dissolve, disperse or subtly shift away.
- Characters should gradually reconstruct after the cursor passes.
- Add subtle metallic reflections that respond to mouse movement.
- Use smooth, sophisticated particle and displacement effects.
Absolutely NO water dripping, liquid splashes or water-ripple effects.

4. Scrolling Animations
Scrolling should drive the visual experience.
- Floating ASCII illustrations should move at different speeds.
- Sections should reveal themselves through smooth transitions.
- Typography and visual elements should animate into position.
- ASCII formations should dissolve and reform between sections.
- Use subtle parallax and depth-based movement.

5. Interaction and Finishing
Everything should feel solid and tactile.
- Buttons and cards should slightly enlarge on hover.
- Metallic violet elements should illuminate on interaction.
- Clicks should trigger subtle expansion and glow.
- Use polished transitions, restrained shadows and realistic metallic
  highlights.

FINAL DIRECTION
Think of a premium digital art studio combined with a futuristic
technology product. The website should feel intentional, expensive,
experimental and beautifully engineered. The two-color identity must
remain consistent throughout. Black should dominate, metallic violet
should provide depth and personality, and typography should remain crisp
and readable. Prioritize solid UI, artistic ASCII animations,
scroll-based storytelling and cursor-reactive dissolving effects. Do not
add unnecessary visual effects just to make the website look animated.
Every animation should have a purpose.
